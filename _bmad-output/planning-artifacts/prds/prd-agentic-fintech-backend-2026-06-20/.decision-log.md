### DL-001 — UCP Discovery Path Alignment
**Decision:** Align discovery endpoint to the official UCP specification path `/.well-known/ucp`, not `/.well-known/ucp-discovery.json` as originally stated in the brain dump.
**Rationale:** The UCP specification (and official docs at ucp.dev) define `/.well-known/ucp` as the canonical discovery path. Deviating would break compliance with any UCP-compliant platform client.
**Status:** Accepted by Parth (2026-06-20).

### DL-006 — OQ-1 Resolution: Mandate Transport
**Decision:** Payment Mandate is transported as the `payment_mandate` field in the JSON request body of `POST /api/complete`. Not the `Authorization` header.
**Rationale:** Mirrors AP2/A2A/MCP JSON-RPC body payload structure for multi-party message exchanges. Aligns with AP2 transport spec intent.
**Impact:** FR-3 updated; `CompleteRequest` Pydantic schema defined in §8 API Contracts.
**Status:** Resolved by Parth (2026-06-20).
